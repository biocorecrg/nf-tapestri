# nf-tapestri
Nextflow pipeline to generate scTAM-seq output files.

<p align="center">
  <img src="dna_met/logo_dnamet.jpg" alt="SALT LOGO" width="500"/>
</p>


nf-tapestri involves three pipelines: 
1) DNAmet+VDJ
2) somatic mutations calling
3) Cell-surface markers.

DNAmet+VDJ and protein pipelines can run independently, while the somatic mutations pipeline depends on the output files generated by the other two pipelines.

## Install

- Use singularity
Edit the `$HOME/.bashrc` file adding:

```
module use /software/as/el7.2/EasyBuild/CRG/modules/all
module load Java/11.0.2
module load Singularity/3.7.0
```

login and logout. From now on you can use singularity. 

- Install nextflow

```
curl -s https://get.nextflow.io | bash
```

You can place the executable in a place with other binaries and add that folder to your `$PATH`

- Install the pipeline

```
git clone git@github.com:biocorecrg/nf-tapestri.git --recurse-submodules 
```

or 

```
git clone https://github.com/biocorecrg/nf-tapestri.git --recurse-submodules 
```

## Downloading the tapestry image
To download the Tapestry Singularity Image, you can use the INSTALL.sh script, which essentially does a `wget` and a `move` to the path with all the singularity directories.

```
sh INSTALL.sh $user $password $path
```

On our HPC, the cache folder for the Singularity images is:

```
/users/bi/public-docs/projects/tapestri/biocorecrg-tapestri-2.0.1.img
```

But you can change it by editing the `nextflow.config` file at the section `singularity.cacheDir`


## Update

To upgrade the pipeline, just run inside the `nf-tapestri` folder

```
git pull --recurse-submodules 
```

# DNAm+VDJ pipeline
This pipeline generates the DNAm counts matrix and **OPTIONALLY** VDJ genes annotation and clonotyping with TRUST4. 

## Outputs per sample: 
- intermediate: .bam, .bam.bai, and .distribution.txt.gz (counts distribution in the whole list of barcodes, before cell calling) 
- output: .barcode.cell.distribution.txt (DNA methylation reads count matrix), .barcode.cell.distribution_filtered.txt (low quality and undigested cells removed), _DoubletDetection (Cell metadata file with doublets information).
- qc_log: stats, number of aligned reads and cells found.
- trust4: trust4 outputs several different output formats.
- trust_cluster: trust4 clonotyping. 

## Parameters
Pipeline parameters are inside the `params.yaml` file:

```
# Parameters
reads: "${projectDir}/test_data/*_read{1,2}.fastq.gz"
genome: "${projectDir}/anno/GRCh37.p13.genome.fa.gz"
panel: "${projectDir}/anno/panel_info.bed" (MB output)
# ampli can be "" in case of cellfinder_scTAMseq.R and it will take the 4th column of the panel file
#ampli: "${projectDir}/anno/Control_amplicons_cell_lines.csv" ## NoHhaI amplicons list in .csv format
ampli: ""
#cellfinder can be cellfinder_scTAMseq.R or cellfinder_MCL_HC.R 
cellfinder: "cellfinder_scTAMseq.R"
undigested: "NO"
CpG_unmeth: "${projectDir}/anno/CpG.always.unmeth.B.extended.panel.csv"  ## always unmet amplicons list in .csv format
nreads: 20000000
vdj: "YES" (whether to run VDJ pipeline)
coord_f: "${projectDir}/anno/hg19_bcrtcr.fa.gz"
ref_trust: "${projectDir}/anno/human_IMGT+C.fa.gz"
hook: ""
email: ""
output: "${projectDir}/outfolder"
```
nreads parameter: 
- 1000M files or bigger, we recommend setting nreads to 50M reads.
- Smaller files, ~100M reads, 20M reads could be more convenient.   

## undigested 
undigested = Yes or o NO, new . The filtering is different whether the sample is undigested or digested.


The command line of the single tools can be tweaked using the file `tools_opt.tsv`. This is the one currently:

```
#tool	extrapars

#tool	extrapars
tapestri-barcode-extract	"--chemistry dna.V2 --no-cut-adapters --decode --barcode-suffix -1"
bwa	"-C -M"
samtools	"-bh -q 30 -F 4 -F 8 -F 0X0100"
picard	"SORT_ORDER=coordinate"
cellfinder_MCL_HC.R	"-c 0.7"
cellfinder_scTAMseq.R "-c 0.5" ## RECOMMENDED 

```

## Running the pipeline

### Old cluster
IMPORTANT: Follow these instructions to run the pipeline at the CRG cluster

1) Log in to the  general nextflow node 

```
ssh username@nextflow.linux.crg.es
```
2) Access to nextflow3 through SSH

```
ssh nextflow3.linux.crg.es
```

Command to run the pipeline:

```
nextflow run main.nf -params-file params.yaml -bg > log.txt
```
We recommend redirecting the `work` folder to a space without backup, like `scratch` (you have to ask SIT for permission to have a folder there).

```
nextflow run main.nf -params-file params.yaml -bg -w //nfs/scratch01/YOURGROUP/work > log.txt
```


### New cluster

1) Log in to the general nextflow node 

```
ssh username@login1.linux.crg.es
```

Command to run the pipeline:

```
cd dna_met
sbatch launch_nf.sh nextflow run main.nf -resume -profile slurm -w YOURSCRATCHFOLDER  -params-file params.yaml -ansi-log false  
```

We recommend redirecting the `work` folder to a space without backup, like `scratch` (you have to ask SIT for permission to have a folder there).

# Mutations pipeline
This pipeline is an adaptation of the MB pipeline for somatic mutation calling in single cells.

## Input and Output:

- Input: output folder from DNAm+VDJ pipeline (** _filtered.txt should be there**)
- Output: H5 and loom files ready to open with Tapestri Insight. 


## Parameters
Pipeline parameters are inside the `params.yaml` file:

```
# Parameters
## intput is the output produced by the dna_met pipeline
input: "${projectDir}/test_data/**"
genome: "${projectDir}/../anno/GRCh37.p13.genome.fa.gz"
gatk_config: "${projectDir}/gatk_config.yaml"

amplicons: "/users/lvelten/project/Methylome/infos/MCL/panel_info.amplicons"
#panel: "${projectDir}/anno/panel_info_filter_variant_calling.bed"
hook: ""
email: ""
```
